# Reckon Copilot: an AI assistant inside the ERP

Reckon Copilot is an AI assistant that lives inside the ERP Desk. It understands the page a user is on, answers from what that user is allowed to see, surfaces insights and alerts, and can prepare ERP actions that the user reviews and approves. It is part of the AI direction of [ReckonERP](https://app.reckon.tech).

## Detailed features

### Desk Copilot
- A copilot panel inside the ERP Desk
- Route-aware context: it knows which screen and record the user is working on
- Permission-scoped: answers respect the signed-in user's access

### Knowledge and answers
- Knowledge retrieval so answers come from your own ERP and documentation
- Caching for responsive replies
- Streaming responses from configurable LLM providers

### Insights and alerts
- Proactive insights and alerts for users
- A Contextual Agent Advisor that suggests what to look at next

### Specialist agents
- Analytics agent for questions about business data
- Forecasting agent for trends
- Anomalies agent that flags unusual records

### Suggested actions
- A catalog of suggested actions with a feedback loop to improve suggestions over time

### Safe, confirmed actions
- Document previews and imports before anything is saved
- Preview-first flow: the user reviews the target and values, then clicks Approve
- The server rechecks native Frappe permissions before applying a transaction
- Every confirmed action is audited

## Built on Frappe and ERPNext

Reckon Copilot is a native Frappe app for Frappe Framework and ERPNext v16 and above, so it works with the same users, roles and permissions as the rest of the ERP.

## Who it is for

Finance, sales, stock and management teams who want faster answers and fewer manual steps inside the ERP, with a person always approving changes.
